# 오토보카 기능 이식 — 우선순위표

> 오토보카(AutoVoca)에서 좋다고 본 기능들을 우리 단어 프로그램(`/student` PWA + 선생님 관리)에 어떻게 녹여 넣을지 정리한 우선순위 매트릭스.
> 기준: **임팩트(학습 효과 + 사용자 만족)** × **구현 난이도(개발 비용 + 데이터 모델 변경)**
> 참고 기준선: [[vocab-self-test-and-flashcards]] 의 8장 체크리스트

---

## 1. 한눈에 — 임팩트 × 난이도 매트릭스

```
임팩트 ↑
 높음 │  ⭐ Quick Win        │  🏔 Big Bet
      │  (먼저 친다)          │  (로드맵에 박는다)
      │                      │
      │  • 약점단어 자동출제   │  • 망각곡선(SM-2) 스케줄러
      │  • 데일리 미션 카드   │  • 단어별 숙련도(0~5) 시각화
      │  • 학습 스트릭/잔디   │  • 예문 빈칸 채우기(AI)
      │  ─────────────────────┼─────────────────────
      │  🧹 Fill-in          │  🪦 Skip/보류
      │  (틈날 때)            │  (지금 안 함)
      │                      │
      │  • 한↔영 짝맞추기     │  • 단어 폭탄/타이핑 레이스
      │  • 푸시 알림         │  • PWA 위젯
      │  • 미니 통계 위젯     │  • STT 발음 평가
      │                      │  • 완전 오프라인 캐싱
 낮음 └──────────────────────┴─────────────────────→ 난이도 높음
        쉬움                                       어려움
```

## 2. 기능별 상세 평가

각 항목: **임팩트(1~5) / 난이도(1~5) / 우선순위 분류**

### A. 망각곡선 자동복습 + 약점단어

| # | 기능 | 임팩트 | 난이도 | 분류 | 현재 시스템 연계 |
|---|---|---|---|---|---|
| A1 | **약점단어 자동 출제** — 셀프테스트/배정 테스트에서 학생별 오답 단어를 가중치 높여 재출제 | 5 | 2 | ⭐ Quick Win | `vocab_completions` 의 오답 기록 활용. 신규 컬럼 불필요. `VocabSelfTest` 의 카드 셔플 단계에서 가중치만 적용 |
| A2 | **단어별 숙련도(0~5)** — 단어 단위로 정답/오답 누적 → 숙련도 산출 → 학생 UI에 표시 | 4 | 4 | 🏔 Big Bet | 신규 테이블 `student_word_mastery(student_id, word_key, level, last_seen_at, next_due_at)` 필요. 대시보드 카드 추가 |
| A3 | **SM-2 망각곡선 스케줄러** — 단어별 next_due_at 자동 갱신, "오늘 복습할 단어" 큐 생성 | 5 | 5 | 🏔 Big Bet | A2 의 테이블 위에 SM-2 알고리즘. Edge Function 또는 클라이언트 계산. 기존 학습모드와 별개 진입점 필요 |
| A4 | **모르는 단어만 다시 학습** 버튼 — 직전 세션의 오답만 모아 즉시 재시험 | 4 | 1 | ⭐ Quick Win | 직전 `cards` 에서 `wrong/timeout` 만 필터해서 `restartFlashcards()` 호출. 컴포넌트 내부 상태만 추가 |

### B. 데일리 미션 + 스트릭/잔디

| # | 기능 | 임팩트 | 난이도 | 분류 | 현재 시스템 연계 |
|---|---|---|---|---|---|
| B1 | **오늘의 단어 N개** 카드 — 학생 홈에 "오늘 학습할 단어 30개" 자동 추천 | 4 | 2 | ⭐ Quick Win | `StudentVocab` 진입 시 미완료 셋 + A1 가중치로 자동 큐 생성. 추가 테이블 없음 |
| B2 | **학습 스트릭/잔디** — 연속 학습일 카운터 + GitHub 스타일 7×N 잔디 | 4 | 2 | ⭐ Quick Win | `vocab_completions.completed_at` 으로 일자별 GROUP BY. 학생 대시보드에 위젯 추가 |
| B3 | **목표 달성 배지/리워드** — "100단어 돌파", "7일 연속" 등 자동 배지 | 3 | 3 | 🧹 Fill-in | 신규 `student_badges` 테이블 또는 클라이언트 계산. 게임화 효과는 있으나 핵심 학습은 아님 |
| B4 | **푸시 알림** — "오늘의 단어 아직 안 했어요" PWA 푸시 | 3 | 4 | 🧹 Fill-in | Web Push + Service Worker. iOS PWA 푸시는 16.4+ 제한. 작업 비용 큼 |

### C. 단어 미니게임 모드

| # | 기능 | 임팩트 | 난이도 | 분류 | 현재 시스템 연계 |
|---|---|---|---|---|---|
| C1 | **영↔한 짝맞추기 게임** — 4×4 카드 매칭. 30초 타이머 | 3 | 2 | 🧹 Fill-in | 신규 컴포넌트 `VocabMatchGame.tsx`. `mode: 'match_game_self_test'` 로 결과 저장 |
| C2 | **단어 폭탄/타이핑 레이스** — 떨어지는 단어를 빨리 입력 | 2 | 4 | 🪦 Skip | 재미는 있지만 학습 효과 대비 개발 비용 큼. 우리 학생층(중고등) 핵심 니즈와 거리 있음 |
| C3 | **객관식 스피드런** — 셀프테스트의 시간 단축 버전 (문항당 2초) | 3 | 1 | ⭐ Quick Win | 이미 있는 `VocabSelfTest` 의 `level` 에 "Lv.0 스피드런" 추가. 거의 무료 |

### D. 예문/문맥 + 음성/위젯 등 기타

| # | 기능 | 임팩트 | 난이도 | 분류 | 현재 시스템 연계 |
|---|---|---|---|---|---|
| D1 | **AI 예문 빈칸 채우기** — 단어가 들어간 영어 문장을 AI 생성 → 빈칸 채우기 모드 | 5 | 4 | 🏔 Big Bet | OpenAI/Claude API 호출 Edge Function 신규. 예문 캐시 테이블 `vocab_example_sentences` 필요. 학습 효과 매우 큼 |
| D2 | **예문 듣고 받아쓰기** — D1 예문을 TTS로 들려주고 통째로 받아쓰기 | 4 | 3 | 🏔 Big Bet | D1 이 선행돼야 함. 기존 듣기 모드 채점 로직 재사용 가능 |
| D3 | **STT 발음 평가** — 학생이 단어 발음하면 음성인식 점수 채점 | 3 | 5 | 🪦 Skip | Web Speech API 정확도 낮음 + 외부 API 비용. 영어 학원 핵심 KPI 아님 |
| D4 | **PWA 위젯/홈화면 단어** — iOS/Android 홈화면 위젯 | 2 | 5 | 🪦 Skip | PWA 위젯은 제한적. ROI 매우 낮음 |
| D5 | **오프라인 학습 캐싱** — 셋 다운로드 → 비행기모드에서도 학습 → 온라인 시 동기화 | 3 | 5 | 🪦 Skip | Service Worker + IndexedDB + 충돌 해결 로직 필요. 현재 사용자 시나리오(학원/집 Wi-Fi)에선 우선순위 낮음 |

## 3. 추천 실행 순서 (스프린트 단위)

### 🚀 Sprint 1 — Quick Win 묶음 (1~2주)
> 데이터 모델 변경 없이 기존 컴포넌트 안에서 처리되는 것들. 효과 즉시.

1. **A4 모르는 단어만 다시** — `VocabSelfTest` 결과화면에 "오답만 다시" 버튼 추가
2. **A1 약점단어 가중치** — `StudentVocab.startFlashcards()` 셔플 단계에서 과거 오답 가중치 적용 (옵션 토글)
3. **C3 스피드런 모드** — `level` 에 Lv.0 추가, 시간만 짧게
4. **B1 오늘의 단어 카드** — 학생 홈 상단 자동 추천 카드
5. **B2 학습 스트릭/잔디** — 학생 대시보드 위젯

→ **데이터 모델 변경 없음**, `vocab_completions` 만으로 다 됨.

### 🏔 Sprint 2 — 숙련도 시스템 (2~3주)
> 단어별 학습 상태를 들고 가야 가능한 것들. 우리 프로그램의 가장 큰 차별화 포인트.

6. **A2 단어별 숙련도 테이블** — 마이그레이션 + Edge Function 갱신 훅 + 학생 UI
7. **A3 SM-2 망각곡선 스케줄러** — A2 위에 알고리즘 + "오늘 복습할 단어" 학습 모드 추가
8. **B3 배지** — A2 데이터를 활용해 자동 부여

### 🧠 Sprint 3 — AI 예문 (2~3주)
> 비용/품질 검증 필요. PoC 부터.

9. **D1 AI 예문 빈칸** — 단어셋 단위 일괄 생성 → 캐시 → 학습 모드 신규
10. **D2 예문 듣고 받아쓰기** — D1 위에 듣기 모드 추가

### 🧹 Fill-in (시간 되면)
- **C1 짝맞추기 게임** — Sprint 사이 쉬어가는 작업
- **B4 푸시 알림** — iOS 푸시 안정화 시점 봐서

### 🪦 보류
- C2 폭탄 게임, D3 STT 발음, D4 위젯, D5 오프라인 — 지금 안 함
